## Features

- Real-time process monitoring with CPU and memory tracking
- Docker container support
- Configurable resource threshold alerts
- Prometheus metrics export
- System-wide resource aggregation
- Cross-platform support (Linux, macOS, Windows)

## 🚀 Quick Start

### Prerequisites

![Go](https://img.shields.io/badge/Go-1.21+-00ADD8?style=flat-square&logo=go)
![Docker](https://img.shields.io/badge/Docker-Optional-2496ED?style=flat-square&logo=docker)

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/process-monitor.git
cd process-monitor

# Install dependencies
go mod download

# Build the project
go build -o process-monitor

# Run it!
./process-monitor
```

### 🎯 One-Line Install

```bash
curl -sSL https://raw.githubusercontent.com/yourusername/process-monitor/main/install.sh | bash
```
